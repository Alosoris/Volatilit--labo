# La volatilité · CLMM

Cours interactif sur la volatilité pour les fournisseurs de liquidité des pools à liquidité concentrée, avec un laboratoire appliqué à six vraies pools (ETH / USDC, WBTC / ETH, WBTC / USDC, HYPE / USDC, SOL / USDC, QQQ / USDG).

Travail de maturité 2026–2027 · Quentin Mathil · groupe 305. Complète la [présentation CLMM](https://dex-v3-presentation.vercel.app/).

Le site tient en un seul fichier, `index.html` (HTML, CSS et JavaScript sans bibliothèque ; formules avec MathJax). Les bougies journalières sont intégrées dans la page ; elles s'arrêtent au 21 novembre 2026.
